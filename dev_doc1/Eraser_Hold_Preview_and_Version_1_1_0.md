# 橡皮按住预览与 1.1.0 版本

## 功能

使用“画笔的橡皮”时，按住鼠标左键擦拭会在当前指针位置显示空心圆，圆内覆盖半透明黑色压暗层。圆的直径沿用橡皮设置中的显示器物理像素值，与实际擦除笔迹所用直径一致。按住并移动时复用同一个圆形控件，只更新位置，不按轨迹创建大量控件。松开鼠标、退出编辑模式、切换工具、图片切换或鼠标捕获丢失时隐藏预览。

预览只属于编辑界面，设置为不参与命中检测；不改变笔记瓦片，也不会写进另存为图片。画布缩放或显示器 DPI 变化时重新计算圆的界面尺寸、位置和边框宽度。窗口失焦时立即取消预览；擦拭中切换工具或退出编辑模式时释放鼠标捕获。直径由已有的橡皮直径参数计算，不声明固定控件大小。

## 版本与发布

项目的 `<Version>` 改为 `1.1.0`，“关于”窗口从程序集读取并显示同一版本。发布使用现有 fd 和 sc 两个配置；输出文件名分别为 `TPV-v1.1.0-fd.exe` 和 `TPV-v1.1.0-sc.exe`。按用户既有要求不运行测试，只进行生成和发布核对。

## 直径与滑条提示

橡皮直径下限沿用画笔下限，上限为同一显示器上的画笔最大直径的五倍。画笔范围保持原有计算方式。画笔和橡皮的直径滑条在鼠标进入及移动时立即显示指针对应的像素值；映射时扣除滑块两端各半个滑块宽度，使提示值与实际滑条值对应。缩放滑条使用同样的指针映射，黑底白字提示在进入时立即打开，离开时关闭，不等待系统默认悬停延时。
