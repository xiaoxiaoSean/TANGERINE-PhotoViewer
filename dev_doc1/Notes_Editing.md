# 笔记编辑功能开发文档

## 1. 功能目标与文件分工

笔记功能允许用户在已打开图片上添加画笔笔迹、文字，并使用“画笔的橡皮”擦除画笔笔迹。编辑过程不直接修改源文件；用户点击“另存为”后，程序才将原始分辨率的图片与有效笔记合成到新文件。普通浏览、缩放、移动、旋转和鸟瞰图仍可使用。文字工具与大图导出的后续实现见 [Text_Notes_and_Large_Export.md](Text_Notes_and_Large_Export.md)。

| 文件 | 职责 |
| --- | --- |
| `MainWindow.xaml` | “笔记”“另存为”及编辑模式菜单、笔迹层、底部状态显示 |
| `MainWindow.xaml.cs` | 原有图片加载、布局、缩放、旋转、滚轮和拖动交互 |
| `MainWindow.Notes.cs` | 工具切换、笔迹状态、菜单显示、坐标转换、另存为调度 |
| `NoteOptionsWindow.cs` | 画笔颜色与直径、橡皮直径设置窗口，以及与实际笔尖一致的实时圆形预览 |
| `AnnotationExport.cs` | 后台按原始分辨率合成、编码、进度与结果验证 |
| `LanguageManager/UiStrings*.resx` | 六套界面文案；资源键按当前界面语言读取，缺项回退至英语 |

所有新增的界面文案都应通过 `LanguageManager.Get(key)` 获取。代码注释遵循 `rules.md`，使用详细英文。选项窗口中的布局通过可用区域比例和 `GridLength(..., Star)` 计算，避免以固定控件尺寸决定显示比例。异常处理应使用项目的 `StageException` 和 stagecode 体系。

## 2. 菜单与编辑模式

图片加载后，“笔记”位于顶部“向右旋转 90 度”的右边，包含“画笔”“画笔的橡皮”和“文字”。左键点击任一工具进入编辑模式；右键点击任一工具打开专门的设置窗口。右键设置不会单纯切换工具。画笔设置包括红、绿、蓝三个颜色通道、十六进制颜色、常用颜色和笔画直径；橡皮设置包括擦除直径。滑块变动时，设置窗口内的圆形预览立即变化。点击“应用”提交设置，“取消”保持原值。

画笔默认使用纯白色，因此“画笔”选项初始为白字黑底。选项文字使用当前选中的画笔颜色；其背景使用每个 RGB 通道的反色，即 `255 - 原通道值`。编辑模式中的工具切换菜单用灰色标记正在使用的工具，未使用的工具保持黑色背景。

编辑模式下，原顶部菜单隐藏，只显示：

1. “你正在编辑文档，正在使用[工具]”：仅显示当前工具，点击不执行操作。
2. “切换工具”：下拉菜单包含画笔、画笔的橡皮和文字。
3. “退出编辑模式”：返回原顶部菜单，不清除已经存在的笔迹。

界面中的编辑状态由 `editingNotes`、`drawingNote`、`savingNotes` 和当前笔迹是否脏等状态共同决定。选中画笔并处于编辑模式，但当前没有落笔时，左下角显示“当前笔画的像素为{0}像素，在图片中为{1}像素”；`{0}` 为当前显示器上的笔画直径，`{1}` 为按当前图片倍率换算的图片像素直径。正在绘画时显示相应工具正在使用；产生未保存笔迹后，退出编辑模式的状态显示当前图片已编辑但尚未保存。保存过程中，左下角持续更新百分比；成功、取消或失败后显示相应结果。退出编辑模式会隐藏编辑状态提示，重新进入时根据保留的笔迹状态显示。

## 3. 笔迹层与脏状态

`NotesCanvas` 承载独立于原图的稀疏位图块。笔迹由一个个原图像素组成，不保存矢量路径。画笔在圆形笔尖覆盖的图片像素位置写入颜色，橡皮将这些像素的透明度清零。绘制或擦除时只更新被触及的块，不重新解码或重绘主图片。图片缩放只改变位图块的显示倍率，因此大图编辑不要求分配一整张全分辨率位图。

位图块使用原图像素坐标保存。缩放和旋转不会重写块内像素，只变换其显示位置。导出前的 `SnapshotNotes()` 复制非空位图块，并按原图像素坐标进行全分辨率合成。`notesVersion` 与 `savedNotesVersion` 标识当前笔记是否存在尚未导出的更改。橡皮完全清除所有块后，图片视为没有编辑，普通菜单中的“另存为”隐藏。

打开另一张图片、卸载图片或替换当前图片时，清除旧图片的笔迹和编辑模式状态。笔迹只能与产生它的图片一起使用；不能让旧图坐标落入新图。

## 4. 鼠标、滚轮与鸟瞰图

编辑模式下，左键在图片上绘制当前工具的笔迹。为避免与绘画冲突，使用鼠标中键拖动图片，或按住空格后用左键拖动图片。普通滚轮、水平滚轮、Ctrl+滚轮缩放、底部缩放滑块以及鸟瞰图的导航和缩放仍按浏览模式工作。已有的大图局部渲染由原来的异步路径负责；笔迹层变化不会请求一次新的主图解码。

笔画范围使用直径，单位是当前显示器的物理像素，与图片像素和图片缩放倍率无关。例如设置为 `100` 像素，屏幕上的笔尖直径就是 `100` 个显示器像素。设当前显示器横向物理像素为 `W`、纵向物理像素为 `H`，笔画直径的起始值是 `(W + H) / 2 / 400`，终止值是 `(W + H) / 2 / 40`，默认值为起始值。画笔和橡皮均使用该范围，设置窗口须把范围显示为“xx像素-yy像素”，由 `DiameterRange` 资源键本土化。落笔时再按当前图片的显示倍率将屏幕直径换算为原图像素直径，写入实际覆盖的位图像素；缩放后继续落笔，笔尖在屏幕上的直径仍保持设置值。

画笔和橡皮选项窗口中的圆形实时显示所选直径在当前显示器上的实际物理像素大小，不因当前图片倍率放大或缩小。窗口预览和图片上的笔尖经过相同的显示器像素与界面坐标换算，超出预览区域时自然裁切。画笔预览圆的填充颜色是当前选中的画笔颜色，背景采用该颜色的反色，保证默认白色笔迹在黑色背景上可见。预览圆属于设置窗口，不写入笔迹，也不会被导出。设置直径和颜色后，后续笔迹使用新的参数；已有笔迹保留原有像素。

## 5. 异步全分辨率另存为

“另存为”只在当前图片存在有效、未保存的笔迹时出现。用户选择目标路径后，程序检查目标路径不得与源文件相同；相同路径以 `NOTES0003` stagecode 报错，避免覆盖原图。保存时先对当前笔迹取快照，并记录版本和旋转角度，再调用 `AnnotationExport.SaveAsync` 在后台合成和编码。UI 线程持续接收进度并更新左下角状态；保存过程不通过屏幕预览图或当前视口截图生成输出。

输出保持原始像素数量和完整图像范围。图片旋转 90° 或 270° 时，输出宽高互换。导出服务会验证尺寸，并在编码器允许的情况下尽量保留源文件元数据和有关编码参数；不同格式或编码器支持范围不同，不能保证每一项元数据原样保留。

保存对话框根据输入格式的编码能力动态选择筛选器：可按原格式编码时，显示“原格式”与 PNG；否则只显示 PNG。筛选器文本使用 `SaveAsOriginalFilter` 和 `SaveAsPngFilter`，其中原格式扩展名填入 `{0}`。数据或路径无效使用 `ANNS0001`；目标格式不可编码时使用 `ANNS0002` 并提示选择 PNG；保存失败和结果验证失败分别使用 `ANNS0003`、`ANNS0004`。

如果后台保存期间笔迹发生变化，保存的是开始时的快照；只有当前版本、源图路径与旋转仍和快照一致，才将当前笔迹标记为已保存。保存失败不会丢弃笔迹。用户可在状态栏看到带 stagecode 的错误说明。

## 6. 本土化资源

主要菜单与状态资源键包括 `Notes`、`Brush`、`BrushEraser`、`SaveAs`、`EditingDocumentWithTool`、`SwitchTool`、`ExitEditMode`、`EditingUnmodified`、`EditedUnsaved`、`EditedSaved`、`BrushInUse` 和 `EraserInUse`。

选项窗口资源键包括 `BrushOptionsTitle`、`EraserOptionsTitle`、`BrushColor`、`BrushRadius`、`EraserRadius`、`BrushRed`、`BrushGreen`、`BrushBlue`、`RadiusPreview`、`Apply` 和 `Cancel`。原有的 `BrushRadius`、`EraserRadius` 与 `RadiusPreview` 资源键保持兼容，但界面文字均使用“直径”。画笔空闲状态使用 `BrushPixelStatus`，其 `{0}` 为显示器像素直径，`{1}` 为当前图片像素直径。无法获取显示器像素尺寸时，以 `NOTES0005` stagecode 和 `DisplayMetricsUnavailable` 文案说明。保存及错误资源键包括 `SaveAsOriginalFilter`、`SaveAsPngFilter`、`SaveAsProgress`、`SaveAsComplete`、`SavedAs`、`SaveFailed`、`SaveAsCannotOverwriteOriginal`、`AnnotationExportUnsupported`、`AnnotationExportInvalid`、`AnnotationExportFailed`、`AnnotationExportVerificationFailed` 和 `EditUnavailable`。

`EditingDocumentWithTool` 的 `{0}` 传入本土化工具名称；`SaveAsProgress` 的 `{0}` 传入整数百分比；`SaveAsComplete` 与 `SavedAs` 的 `{0}` 传入目标文件路径。不要拼接固定语言的句子。

## 7. 验证方法

1. 打开普通图和大图，确认菜单位置；右键点击两个工具，确认窗口出现并实时显示颜色或直径变化。
2. 分别画点和连续笔迹，局部擦除后再全部擦除，确认“另存为”的出现与消失符合最终笔迹状态。
3. 在编辑模式中切换工具，确认顶部只保留三个菜单，灰色背景、底部状态和实际工具一致。
4. 编辑时测试中键拖动、空格加左键拖动、纵向和横向滚轮、Ctrl+滚轮、缩放滑块与鸟瞰图；缩放及旋转后确认笔迹位置正确。
5. 对大图导出新文件，检查输出宽高、笔迹细节与原文件不变；保存期间确认百分比实时变化，主图没有因每次画笔移动而重新解码。
6. 测试原格式不支持编码、目标路径等于源路径及写入失败，确认状态栏提示和 stagecode 正确。
